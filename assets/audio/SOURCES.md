# Audio sources

All clips under `assets/audio/` were **synthesized procedurally** (Python + NumPy + ffmpeg/libvorbis) for this project — no third-party samples.

| File | Role | Notes |
|------|------|-------|
| `giggle_01.ogg` / `giggle_02.ogg` | Tickle pulse giggles | Female-ish formant bursts (~1.1–1.3s), near-full scale |
| `laugh_intense.ogg` | Intense / multi-tickler / stamina-depleted | Cascading laugh (~2.2s) |
| `ambience_city.ogg` | Mission loop | Wind, sparse distant impacts, far siren-ish wail (~8s seamless) |
| `ambience_zombies.ogg` | Mission loop | Female-ish distant moans/growls/shrieks (~6s seamless) |
